재재스튜디오(대표 이경재, 이하 "운영자")는 웹·앱에서 개발 환경에 원격 접속할 수 있도록 돕는 아델리 터미널(이하 "서비스")을 운영하며 「개인정보 보호법」 등 관계 법령을 준수합니다.

## 1. 처리할 수 있는 정보

| 구분 | 처리 항목 |
| --- | --- |
| 에이전트·기기 | 에이전트 식별자, 기기 이름, 운영체제·버전, 앱 버전, 연결 상태 |
| 페어링·접속 | 이용자가 입력한 Tailscale URL 등 접속 주소, 페어링 정보, 인증·세션 토큰, 접속 시각 |
| 터미널 기능 | 이용자가 입력한 명령과 표시되는 출력. 구성에 따라 이용자 기기와 에이전트 사이에서 전송·일시 처리될 수 있습니다. |
| 기술 기록 | IP 주소가 제공되는 경우 해당 주소, 연결·오류·보안 로그와 성능 정보 |
| 문의 | 이메일, 문의 내용과 이용자가 첨부한 진단정보 |

비밀번호, API 키, SSH 키, 개인키 등 비밀정보를 터미널 명령이나 문의에 불필요하게 노출하지 마세요. 인증 토큰은 서비스 연결에 필요한 범위에서만 처리합니다.

## 2. 처리 목적

- 에이전트와 웹·앱의 페어링 및 원격 터미널 세션 제공
- 연결 상태 표시, 세션 유지와 요청한 명령 전달
- 비인가 접근 방지, 장애·성능 분석과 보안 대응
- 문의, 분쟁 및 중요한 보안 공지 처리

## 3. 처리 위치와 보유 기간

설치형 에이전트와 Tailscale 등 이용자 환경에서 직접 처리되는 정보는 해당 환경의 설정과 정책에 따릅니다. 운영자가 관리하는 시스템에 저장되는 세션·오류 기록은 기능 제공과 보안 대응에 필요한 최소 기간만 보관하고 목적 달성 후 삭제합니다. 계정 또는 기기 연결 해제와 삭제 요청 시 법령상 의무나 진행 중인 보안·분쟁 대응에 필요한 정보를 제외하고 지체 없이 파기합니다.

터미널 명령과 출력의 영구 저장 기능을 제공하게 되는 경우 저장 여부, 위치, 암호화 방식과 보유 기간을 기능 활성화 전에 별도로 알립니다.

## 4. 외부 서비스·위탁·국외 이전

Tailscale 등 이용자가 선택하거나 설치한 네트워크 서비스에는 해당 사업자의 약관과 개인정보처리방침이 적용됩니다. 운영자가 외부 인프라에 처리를 위탁하거나 개인정보를 국외 이전하는 경우에는 실제 처리 전에 대상, 목적, 항목, 국가, 방법 및 기간을 공개하고 필요한 동의·보호조치를 시행합니다. 별도 동의나 법률상 근거 없이 개인정보를 다른 제3자에게 제공하지 않습니다.

## 5. 권리와 안전성 확보조치

이용자는 개인정보의 열람, 정정·삭제, 처리정지 및 동의 철회를 요청할 수 있습니다. 운영자는 연결 토큰 보호, 접근권한 최소화, 전송구간 보호, 비밀정보 분리, 접속기록 관리와 보안 업데이트 등 합리적인 조치를 시행합니다. 이용자도 운영체제·에이전트를 최신 상태로 유지하고 접속 URL과 토큰을 타인에게 공개하지 않아야 합니다.
