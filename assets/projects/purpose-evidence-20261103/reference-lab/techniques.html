Lusion → FORM

샘플 열기 ↗ · 원본 ↗

3D·모션·인터랙션을 결합하는 스튜디오라는 공식 소개를 참고했습니다. 아래 조형물과 움직임은 자체 설계입니다.

중첩 조형물

engine.js / mode === lusion

반지름이 다른 토러스 5개에 독립 회전축을 부여합니다. 그룹 회전과 내부 회전을 분리해 형태의 변화를 만듭니다.

튜닝: 그룹: scroll×5, 내부: time×0.12. 내부 회전을 줄이면 단일 오브젝트처럼, 늘리면 구조가 풀리는 느낌입니다.

스크롤·카메라 합성

engine.js / frame(), damp()

문서 진행률을 0~1로 정규화하고 시간 기반 지수 감쇠를 적용합니다. 스크롤은 카메라와 조형물의 큰 이동을, 포인터는 작은 시차만 담당합니다.

튜닝: damping 5.5: 값이 클수록 즉각 반응. pointerParallax 0.65: 값이 클수록 마우스에 따른 좌우 시차가 큽니다.

재질과 조명

engine.js / mat(), sun, fill

금속성 0.8, 거칠기 0.2의 표면에 방향광과 보조 점광원을 배치합니다. 톤매핑과 부드러운 그림자로 입체감을 만듭니다.

튜닝: 거칠기를 낮추면 하이라이트가 좁아집니다. 이 샘플은 환경맵·후처리 블룸을 사용하지 않습니다.

Igloo → BOREAL

샘플 열기 ↗ · 원본 ↗

몰입형 공간과 이동감을 참고한 해석입니다. 원본의 내부 렌더링 코드와 카메라 경로는 확인하지 않았습니다.

카메라 레일

engine.js / updateCameraRail()

결정과 링의 월드 좌표를 고정하고 카메라 z를 10에서 -39로 이동합니다. 주시점은 항상 9단위 앞에 둡니다. 화면 회전이 아니라 공간을 통과하는 운동 시차가 생깁니다.

튜닝: z = 10 − p×49. 이동거리를 늘리면 더 멀리 전진하며, 주시점 거리를 줄이면 방향 변화가 예민해집니다.

측면·높이 곡선

engine.js / updateCameraRail()

x = sin(p×2π)×1.3, y = 2.5 + sin(p×π)×1.2. 직선 전진에 완만한 횡이동과 상승을 합칩니다.

튜닝: 곡선 진폭을 과하게 높이면 회랑 가장자리와 겹칠 수 있습니다. 카메라 경로와 주변 물체 간격을 함께 조절해야 합니다.

깊이 단서

engine.js / scene.fog, igloo 초기화

전경의 결정, 일정 간격의 링, 거리 안개를 함께 배치합니다. 가까운 물체의 빠른 이동과 먼 물체의 느린 이동을 비교할 수 있습니다.

튜닝: 안개 밀도 0.025, 링 간격 10. 밀도가 높으면 원경이 빨리 사라집니다. 원본의 얼음 셰이더를 복제한 것은 아닙니다.

Unseen → AFTERLIGHT

샘플 열기 ↗ · 원본 ↗

공식 페이지의 드래그 탐색, 클릭·홀드 안내, 사운드 토글을 참고했습니다. 샘플은 클릭 선택과 관성 회전으로 재구성했습니다.

관성 드래그

engine.js / pointer events, updateOrbit()

포인터 이동량을 목표 방위각으로 변환합니다. 손을 놓을 때의 각속도를 적분하고 exp(-friction×dt)로 감쇠합니다. 실제 카메라 위치는 목표각을 지연 추종합니다.

튜닝: orbitSensitivity 0.006 rad/px, orbitFriction 4/s. 감쇠값을 낮추면 놓은 뒤 더 오래 움직입니다. 입력 속도 계산에 최소 8ms를 적용하고 방출 각속도를 ±2.5rad/s로 제한해 빠른 드래그의 폭주를 막습니다.

레이캐스팅 선택

engine.js / pick(), openProject()

화면 좌표를 -1~1로 변환해 카메라에서 광선을 쏘고 첫 교차 오브젝트를 선택합니다. 드래그 거리 8px 미만만 클릭으로 인정합니다.

튜닝: 8px 임계값을 낮추면 작은 손떨림도 드래그로 인식합니다. 키보드 1~3 및 이름 버튼은 동일한 상세보기 함수를 호출합니다.

사운드 피드백

engine.js / ping()

사용자가 소리를 켠 뒤에만 Web Audio를 생성합니다. 선택한 작품에 따라 음높이가 달라지고 게인은 0.65초 동안 지수적으로 감소합니다.

튜닝: 220 + index×110 Hz, gain 0.08. 오디오 파일 없이 합성한 선택 피드백입니다. 원본의 공간 음향·배경음 재현은 포함하지 않습니다.

Bruno → FIELD TRIP

샘플 열기 ↗ · 원본 ↗

공식 포트폴리오의 운전 탐색, 방향키/WASD, 브레이크, 리셋과 카메라 조작 안내를 참고했습니다. 샘플은 소규모 아케이드 주행입니다.

가속·저항 모델

engine.js / updateVehicle()

가속 입력을 속도에 누적하고 exp(-drag×dt)로 저항을 적용합니다. 속도는 전진·후진 한계로 제한합니다. Space는 감쇠를 8/s로 올립니다.

튜닝: driveAcceleration 9, driveDrag 1.7, maxSpeed 12. 단위는 월드 좌표 기준이며 화면의 km/h는 시각적 환산값입니다.

속도 의존 조향

engine.js / updateVehicle()

정지 상태에서는 회전하지 않고 속도 부호·크기에 따라 회전합니다. 후진하면 조향 방향도 바뀝니다. sin/cos로 위치를 적분합니다.

튜닝: driveSteering 1.9 rad/s, clamp(speed/4,-1,1). 조향량과 속도를 함께 높이면 급격한 원운동이 됩니다.

추종 카메라

engine.js / updateVehicle()

차량 위치에 (9,10,12) 오프셋을 더한 목표 카메라를 지수 감쇠로 따라갑니다. 주시점은 차량 주변에 유지합니다.

튜닝: followDamping 4. 낮추면 카메라가 뒤늦게 따라오고 높이면 차량에 단단히 붙습니다.

장소와 UI 연결

engine.js / hotspots, openProject()

장소와 차량의 평면 거리가 5 미만이면 이름을 표시하고 Enter로 상세를 엽니다. 리셋·탭 이탈 시 입력 상태를 정리합니다.

튜닝: 경계 제한은 있지만 건물 충돌·강체 물리·서스펜션·멀티플레이는 없습니다. 물리엔진과 동일하다고 해석하지 않아야 합니다.

Dennis → JUNE

샘플 열기 ↗ · 원본 ↗

디자인·인터랙션 포트폴리오의 편집적 구성에서 착안했습니다. 아래 메뉴 곡선과 추종 값은 자체 제작한 값입니다.

커서 추종 미리보기

editorial.js / frame(), selectPreview()

작품 행에 진입하면 미리보기 내용을 바꾸고 커서 목표점을 시간 기반 지수 감쇠로 따라갑니다. 투명도와 크기는 별도로 전환합니다.

튜닝: cursorDamping 12. 값이 낮으면 뒤따르는 잔상이 강해집니다. pointer-events:none으로 원래 행의 입력을 가리지 않습니다.

마그네틱 버튼

editorial.js / pointermove

버튼 중심과 포인터의 차이에 강도를 곱해 버튼을 이동시킵니다. 반경을 벗어나면 원위치로 돌아옵니다.

튜닝: magnetStrength 0.28, magnetRadius 110px. 큰 변위는 클릭 위치가 흔들릴 수 있으므로 강도를 제한합니다.

곡선 메뉴 전환

editorial.js / setMenu(), lab.css / .menu-panel

translateX와 왼쪽 border-radius를 함께 전환해 패널이 펴지는 인상을 만듭니다. 열림 상태, 배경 inert, 포커스 제한, Escape 복귀를 함께 관리합니다.

튜닝: 650ms, cubic-bezier(.65,0,.2,1). 원본의 SVG 곡선이나 페이지 전환 엔진을 그대로 구현한 것은 아닙니다.

스크롤 타이포그래피

editorial.js / frame()

큰 글자를 고정된 속도로 자동 재생하지 않고 세로 스크롤 거리에 비례해 좌우 이동시킵니다.

튜닝: marqueeRate 0.32. 모션 감소 설정이면 이동과 커서 미리보기를 비활성화합니다.

옮겨 쓸 때의 계약

  1. 시간은 초 단위 dt, 스크롤은 0~1 진행률을 전달합니다. 지수 감쇠는 프레임 수가 아니라 경과 시간으로 계산합니다.
  2. engine.js는 #world 캔버스와 .progress를 필요로 합니다. 카메라 함수는 scene/camera/config를 인자로 받는 모듈로 분리하면 다른 페이지에 이식할 수 있습니다. 현재는 공통 데모 엔진이며 독립 npm 패키지는 아닙니다.
  3. 스크롤 모드와 드래그 모드를 분리합니다. 드래그 중에는 클릭을 억제하고 pointercancel·blur에서 입력을 정리합니다.
  4. 차량 모델 크기·월드 거리·카메라 오프셋은 같은 좌표 단위를 사용해야 합니다. 아트만 교체해도 배치와 반경은 함께 검토합니다.
  5. 모션 감소 환경에서는 장식 회전을 멈추고 스크롤 보간을 생략합니다. 사용자 직접 조작은 유지합니다. DPR은 1.75로 제한하고 그림자 해상도는 1024입니다.

직접 구현한 부분과 남은 부분

포함: 3D 장면·카메라 경로·조명·스크롤 추종·관성 드래그·선택 판정·음 합성·차량 주행·추종 카메라·DOM 메뉴·포커스 관리·미리보기 추종·파라미터 패널.

미포함: 원본 3D 모델/텍스처/영상, 커스텀 물·얼음 셰이더, 물리엔진 충돌, 고급 포스트프로세싱, 원본의 모든 전환 구간·로딩 전략. 해당 기법들은 이번 구현을 근거로 ‘확보했다’고 간주하지 않습니다.

핵심 수식

follow = lerp(current, target, 1 − exp(−lambda × dt))
velocity *= exp(−friction × dt)
angle += angularVelocity × dt
position += headingDirection × speed × dt
