# Reference Lab — 2026-10-22

`index.html`을 Chrome에서 열어 다섯 샘플을 선택합니다. 설치·서버·외부 CDN 없이 실행됩니다. vendor 폴더를 함께 보관하세요.

- lusion.html — FORM: 중첩 조형물과 스크롤·포인터 카메라
- igloo.html — BOREAL: 고정 공간을 통과하는 카메라 레일
- unseen.html — AFTERLIGHT: 관성 드래그, 레이캐스팅 선택, 합성 사운드
- bruno.html — FIELD TRIP: 아케이드 운전과 추종 카메라
- dennis.html — JUNE: 메뉴, 마그네틱 버튼, 커서 미리보기, 타이포그래피
- techniques.html — 커스텀 함수·튜닝 값·재사용 계약·원본 대비 구현 범위

원본 사이트의 브랜드·아트워크·소스 복제본이 아니라 특징적 인터랙션을 해석한 별도 콘셉트 샘플입니다. Three.js는 MIT 라이선스로 사용하며 vendor/LICENSE-three.txt에 원문을 보관합니다. three.js는 three.module.js의 export를 브라우저 전역으로 바꾼 로컬 번들입니다.

오른쪽 위 ‘조절값’은 현재 페이지의 CONFIG를 변경합니다. 새로고침하면 기본값으로 돌아갑니다. 영구 적용하려면 engine.js 또는 editorial.js의 CONFIG를 수정합니다.
