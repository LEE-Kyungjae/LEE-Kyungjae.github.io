## Setup

1. Download and extract the zip archive.
2. Open the extracted directory in a terminal.
3. Run `./start-agent.sh`.
4. Enter the displayed `Tailscale URL` in the app’s pairing screen.

## Notes

- The current package supports macOS on Apple Silicon.
- Intel macOS, Windows and Linux require separate builds.
